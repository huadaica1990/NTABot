# Scout Engine – Features

## Map Scouting (ScoutEngine)

Scans map tiles around a reference origin using OCR, classifying each tile by type (lv1–lv5, ally, enemy, terrain, etc.).

**Config fields:** Origin X/Y, Up/Down/Left/Right range (tiles).

Results displayed in the scout treeview (columns: X, Y, Loại, Mô tả).
